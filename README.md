## 🚀 Hướng Dẫn Tải Về & Chạy Dự Án

### 1. Tải dự án về máy
- **Cách A (Dùng Git)**:
  ```bash
  git clone https://github.com/your-username/your-repo-name.git
  ```
- **Cách B (Tải ZIP)**:
  Nhấn nút **Code** trên GitHub -> Chọn **Download ZIP** -> Giải nén file.

---

### 2. Cách chạy website (Chọn 1 trong các cách sau)

#### 🔹 Cách 1: Mở trực tiếp (Nhanh nhất)
1. Mở thư mục dự án vừa tải về.
2. Nhấp đúp chuột vào file **`index.html`** (hoặc chuột phải chọn mở bằng Chrome / Edge / Firefox / Safari).

---

#### 🔹 Cách 2: Dùng VS Code Live Server
1. Mở thư mục dự án bằng **Visual Studio Code**.
2. Chuột phải vào file `index.html` -> Chọn **Open with Live Server** (phím tắt `Alt + L, Alt + O`).
3. Website sẽ tự động mở tại `http://127.0.0.1:5500`.

---

#### 🔹 Cách 3: Dùng dòng lệnh (Python / Node.js)
- **Nếu dùng Python**:
  ```bash
  python -m http.server 8000
  ```
  Truy cập: `http://localhost:8000`

- **Nếu dùng Node.js**:
  ```bash
  npx serve .
  ```
  Truy cập: `http://localhost:3000`
